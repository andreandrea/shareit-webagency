# Shareitwebagency

Sito corporate statico pronto per Vercel.

## Sviluppo locale

Aprire `index.html` oppure servire la cartella con un server statico.

## Deploy su Vercel

Importare il repository come progetto **Other** senza build command. La directory di output è la root del repository.

Le pagine disponibili sono:

- `/`
- `/chi-siamo`
- `/contatti`
- `/page-template`
